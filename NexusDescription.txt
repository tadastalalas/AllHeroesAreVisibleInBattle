[color=#ffff00][size=4]Features[/size][/color]
[color=#ffd966]Outlines heroes in campaign battles in the colour of their role: your clan and companions, friendly heroes, enemy heroes, friendly formation captains and the friendly army general.[/color]
[color=#93c47d]Hold mode (outlines only while the key is held) or Toggle mode (press once to turn on, again to turn off).[/color]
[color=#ffd966]A keyboard / mouse key and a controller button. Both work at the same time.[/color]
[color=#93c47d]Hero names above their heads, in the same colour as the outline.[/color] ([color=#6aa84f]on[/color]/[color=#e06666]off[/color])
[color=#ffd966]Only heroes within a set distance from the camera are outlined.[/color]
[color=#93c47d]Heroes who join the battle later are outlined too.[/color]
[color=#ffd966]Works with or without Mod Configuration Menu.[/color]
[color=#93c47d]Translations for 12 languages.[/color]

[center][color=#6fa8dc][size=4]Additional languages included (using copilot ai translation)[/size][/color]
Português (BR), 简体中文, 繁體中文, Deutsch, Français, Italiano, 日本語, 한국어, Polski, Русский, Español (LA), Türkçe[/center]

[color=#ffff00][size=4]Settings[/size][/color]
[color=#ffd966]Highlight Mode[/color] - Hold / Toggle, default [color=#93c47d]Hold[/color]
[color=#ffd966]Keyboard Key[/color] - default [color=#93c47d]Left Alt[/color] (Alt, Ctrl, Shift, Tab, Caps Lock, Tilde, Space, letters, mouse buttons, F1 to F12, or None)
[color=#ffd966]Controller Button[/color] - default [color=#93c47d]None[/color] (bumpers, triggers, stick clicks, View, Menu, D-Pad, face buttons)
[color=#ffd966]Highlight Distance[/color] - 10 to 200 m, default [color=#93c47d]30[/color]
[color=#ffd966]Show Names[/color] - default [color=#6aa84f]on[/color]
[color=#ffd966]Logging for debugging[/color] - default [color=#e06666]off[/color]

[color=#6fa8dc]With Mod Configuration Menu:[/color] change them in game under [color=#ffd966]Options > Mod Options[/color]. Changes apply at once.
[color=#6fa8dc]Without Mod Configuration Menu:[/color] open [color=#ffd966]Modules[/color]\[color=#f1c232]AllHeroesAreVisibleInBattle[/color]\[color=#ffd966]ModConfiguration.xml[/color] in any text editor. The file is read every time a campaign is started or loaded. If it is deleted or broken, the mod creates a new one with the default values.
[color=#6fa8dc]Updating:[/color] the old [color=#ffd966]Config.xml[/color] is replaced by [color=#ffd966]ModConfiguration.xml[/color] - set your values again there.

[color=#ffff00][size=4]Game versions[/size][/color]
[color=#93c47d]1.5.7[/color], [color=#93c47d]1.4.8[/color], [color=#93c47d]1.4.7[/color] in the same download. The mod picks the right files for your game by itself.

[color=#ffff00][size=4]Compatibility[/size][/color]
Can be added/removed [color=#93c47d]anytime[/color].
Does [color=#93c47d]not add data[/color] to save game files.
[color=#93c47d]No Harmony patches[/color], uses only mission events.
Works with [url=https://www.nexusmods.com/mountandblade2bannerlord/mods/4633]Immersive Battlefields[/url] - its formation captains are outlined in [color=#3366ff]Blue[/color].

[color=#ffff00][size=4]Installation[/size][/color]
Updating? [color=#e06666]Delete the old mod folder first[/color], never overwrite it.
Advisable to use [color=#ffd966]7zip[/color] to extract archive.
Put it in [color=#ffd966]Mount & Blade II Bannerlord[/color]\[color=#f1c232]Modules[/color] folder.
Enable the mod in the launcher. [url=https://www.nexusmods.com/mountandblade2bannerlord/mods/612]Mod Configuration Menu[/url] (if you use it) must be above it.

[color=#ffff00][size=4]Found a problem?[/size][/color]
Generate a crash report link using [url=https://www.nexusmods.com/mountandblade2bannerlord/mods/2018]ButterLib[/url] mod. How to do that the mini guide is here: [url=http://bannerlordmodding.lt/guides/how_to_report_a_crash/]How To Report A Crash[/url]
Turn on [color=#ffd966]Logging for debugging[/color] in [color=#ffd966]MCM[/color] settings or [color=#ffd966]ModConfiguration.xml[/color] in mod folder, [color=#f6b26b]repeat the problem[/color], then attach the file from [color=#ffd966]Modules[/color]\[color=#f1c232]AllHeroesAreVisibleInBattle[/color]\[color=#ffd966]logs[/color] to your [url=https://www.nexusmods.com/mountandblade2bannerlord/mods/2018]ButterLib[/url] crash report.
